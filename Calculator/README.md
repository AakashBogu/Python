# 🔢 Simple Python Calculator

An interactive, user-friendly command-line calculator written in Python. It supports essential arithmetic operations with built-in input validation and error handling.

---

## ✨ Features

- **Standard Arithmetic**:
  - Addition (`+`)
  - Subtraction (`-`)
  - Multiplication (`*`)
  - Division (`/`)
- **Advanced Operations**:
  - Modulus / Remainder (`%`)
  - Exponentiation / Power (`**`)
- **Error Handling**:
  - Catches invalid non-numeric inputs gracefully.
  - Handles division and modulo by zero (`ZeroDivisionError`).
- **Clean Result Formatting**: Automatic formatting to display clean integers where applicable.
- **Continuous Loop**: Run consecutive calculations until you choose to exit.

## ⚙️ Setup & Usage

### 1. Requirements
- Python 3.6 or higher (uses built-in modules only; no third-party dependencies required).

### 2. Run the Script

Navigate to the project folder and run:

```bash
python calculator.py
```
